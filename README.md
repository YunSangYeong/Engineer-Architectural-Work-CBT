# 건축기사 필기 CBT

React 19·TypeScript·Vite 기반의 비공식 학습 앱입니다. `YunSangYeong/electrician-cbt`의 화면·시험·복습·저장 기능을 실제 소스로 재사용했습니다. 원본 저장소는 변경하거나 재배포하지 않았습니다.

- 앱 기준: `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`. MIT 고지 보존. 기존 작업 저장소는 README만 있었고 AGENTS.md는 없었습니다. 새 AGENTS.md에 표준 참조를 연결했습니다.
- 실전 모의시험, 랜덤 문제풀이, 즉시 해설, 오답 재학습, 북마크, 과목별 통계, 최근 시험, 로컬 JSON/CSV 등록·중복 제거·근거 입력 후 검수 승인.

- 절대 종료 시각 기반 타이머, 답안 변경·새로고침 복원·만료 자동 제출·중복 제출 방지.
- 모바일 메뉴의 독립 세로 스크롤, 동적 뷰포트 높이, 실제 휠·터치 입력 회귀 검사.
- 비공식 표시는 사이드바·푸터에만, 규칙·문항 검증 한계는 문제은행 관리와 이 문서에 표시. 실제 저장 실패/손상 경고는 유지.

## 시험 규칙 확인 상태

**공식 원문 대조 미완료입니다. 공식 시험 재현이나 최신 출제기준 충족을 주장하지 않습니다.**

2026-10-25 Q-Net 건축기사 종목 페이지 요청이 `Tunnel connection failed: 403 Forbidden`으로 차단됐습니다. 확인 대상 URL: https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=1630 . 이는 원문을 읽었다는 뜻이 아닙니다. 별도 공식 법령 원문이나 기출 원문도 확보하지 않았습니다.

`src/qualification.ts`에 **학습용 잠정 설정**을 분리했습니다. 건축계획·건축시공·건축구조·건축설비·건축법규, 과목별 20문항/총 100문항, 150분, 객관식 4지선다. 과목별 정답 수 × 5점으로 환산하며 평균 60점 이상 **그리고 모든 과목 40점 이상**일 때 합격입니다. 미응답은 오답으로 처리합니다. 표시 반올림값으로 합격을 판정하지 않습니다. 공식 원문 접근이 가능해진 뒤 과목·시간·배점·기준을 다시 대조해야 합니다.

## 실제 기본 문제은행

| 과목 | 개념형 | 계산 조건 변형 | 합계 |
| --- | ---: | ---: | ---: |
| 건축계획 | 20 | 0 | 20 |
| 건축시공 | 20 | 300 | 320 |
| 건축구조 | 20 | 300 | 320 |
| 건축설비 | 20 | 300 | 320 |
| 건축법규 | 20 | 0 | 20 |
| 전체 | 100 | 900 | 1,000 |

- 원문 기출 **0**, 복원 **0**, 자체 제작 **1,000**. 출제 연도·회차는 모두 `null`입니다. 기본 JSON에 실제 등록된 내부 검수 문항 1,000개, 수량 목표 대비 부족 **0개**입니다. 전문가 검수 완료 문항이나 공식 자료 대조 완료 문항은 **0개**입니다.
- 계산형은 **9유형 × 100조건**입니다. 개념형 100개와 합쳐 독립 템플릿은 109개입니다. 1,000개 독립 개념 또는 1,000개 기출이 아닙니다. 숫자 변형은 동일 원리를 반복하며 이 사실을 숨기지 않습니다.
- AI 일반 지식으로 작성했습니다. 읽지 않은 교재·법령·공식 출제기준을 근거로 인용하지 않습니다. sourceUrl은 **작성 위치**이며 외부 정답 증빙이 아닙니다. 기출 재배포 이용 조건을 확인하지 못해 타 사이트 기출을 복제하지 않았습니다.
- 개념 원고 및 계산 템플릿의 조건·정답·문장을 내부 검토했습니다. 계산 900개는 생성기와 분리된 TypeScript 수식으로 단위·정답 번호·동치 보기를 자동 확인합니다. 이는 외부 전문가 검수, 공식 기준 대조, 모든 해설 문장의 독립 검수와 다릅니다.
- 법규 20개는 일반 용어와 법령 확인 절차 중심입니다. 현행 수치 규정·산정 예외·조문별 기출을 다루지 않습니다. 계획/법규의 다양성과 과목 간 분포가 제한적이므로 **완전한 시험 대비 문제은행으로 평가하지 않습니다**.
- ID와 NFKC 정규화 본문·정렬 보기로 중복 검사합니다. 의미 검토는 개념 원고와 9개 계산 템플릿 단위입니다. 숫자 조건 변형은 허용한 반복 유형으로 별도 집계합니다. 전체 문항의 외부 독립 의미 중복 검토는 미완료입니다.
- 모의시험에서는 과목별 family마다 우선 한 문제를 뽑고, 부족할 때만 다른 ID로 보충합니다. 기본 은행은 과목별 최소 20개 유형 그룹이 있어 family 반복 없이 구성됩니다.
- 새 자체 제작 자료와 등록 예제는 CC BY 4.0, 앱 코드는 MIT입니다. `LICENSE` 참조. 타인이 로컬로 등록한 자료의 권리는 각 자료에 따릅니다.

## 개발과 검증

Node.js **24.19.0** (`.node-version`), npm lockfile 사용.

```bash
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

이 클라우드에는 `/usr/bin/chromium`이 있어 별도 다운로드 없이 다음 명령으로 검사했습니다.

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

재생성: `python3 scripts/generate_bank.py`. 입력 `scripts/concepts.txt`, 정해진 순서·조건·ID·보기 순환을 사용하며 난수나 외부 자료에 의존하지 않습니다. 재생성 전후 JSON/CSV가 동일한지 검사합니다. 단위·브라우저 검사 결과와 한계는 [검증 보고](docs/verification.md)를 확인하세요.

## 기록과 개인정보

`architectural-work-cbt:v1` namespace로 이 origin의 localStorage에 저장합니다. 원본 전기기능사 키와 분리했습니다. 최근 응답 5,000개·시험 30회, 진행 중 시험과 연습·오답·북마크·로컬 등록 문항을 보관합니다. 통계도 그 보관 범위를 기준으로 합니다. JSON 백업 **내보내기**는 제공하지만 백업 전체 복원 UI는 없습니다. 초기화는 확인창을 거치며 기본 문제은행을 지우지 않습니다. 손상된 기록은 자동 덮어쓰지 않습니다.

서버·로그인·유료 API·개인정보 전송은 없습니다. 다른 기기/origin/시크릿 창과 iframe의 저장 제한은 브라우저에 따릅니다. 기기 시계를 조작하면 타이머에 영향을 줄 수 있으며 공식 감독 시험이 아닙니다.
